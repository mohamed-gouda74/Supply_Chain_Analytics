
# Supply Chain & Logistics Dashboard

## 📌 Project Overview
This project focuses on analyzing supply chain and logistics performance using Microsoft Excel. The interactive dashboard provides insights into revenue, profit, costs, shipping expenses, suppliers, products, warehouses, and order status.

The goal is to transform supply chain data into meaningful business insights and support data-driven decision-making.

## 🎯 Project Objectives
- Monitor revenue, profit, and operational costs.
- Analyze profitability across products, suppliers, countries, and warehouses.
- Track shipping costs and their distribution.
- Understand order status and logistics performance.
- Identify top-performing products and suppliers.
- Explore business performance by year, month, and location.

## 📊 Key Performance Indicators (KPIs)
- **Total Revenue:** 4.78B
- **Total Profit:** 1.59B
- **Total Cost:** 3.19B
- **Total Shipping Cost:** 1.94M
- **Profit Margin:** 33.34%

## 📈 Dashboard Highlights
- **Top 5 Products:** Analyze products by profit and revenue.
- **Supplier Performance:** Compare suppliers based on revenue.
- **Profitability Analysis:** Explore performance by country, warehouse, and customer location.
- **Order Status Analysis:** Visualize the distribution of order statuses.
- **Shipping Cost Breakdown:** Analyze shipping expenses.
- **Interactive Filters:** Filter dashboard insights by supplier, year, month, warehouse, and country.
